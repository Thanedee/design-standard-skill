# Design Standard: a Claude skill

A professional design standard for any visual: social posts, carousels, flyers, logos, slides, video, print, web and AI-generated images. It covers perception research, layout, typography, colour (including the colour wheel and pairing guides), imagery, data visualisation, accessibility (WCAG 2.2), platform sizes and safe zones, motion, print production, UI, Nigerian cultural context, legal rules, guardrails for AI-generated images, and quality-control checklists.

## Install in Claude

1. Download `design-standard.zip` from this repository (or zip the `design-standard` folder yourself, with the folder at the top level of the zip).
2. In Claude, open **Customize > Skills** and upload the zip.
3. Make sure code execution is turned on in **Settings > Capabilities**.
4. Ask Claude to create or review any design; it will apply the standard automatically.

## Contents

- `design-standard/SKILL.md`: the core rules Claude reads first.
- `design-standard/references/`: the full guide, one file per section, with sources.
- `design-standard/assets/`: the colour wheel and colour harmony images.

The full guide is also available as a PDF: `Complete_Design_Guide.pdf`.

This is general design guidance, not legal advice. Platform sizes and regulations change; check them before relying on them.
