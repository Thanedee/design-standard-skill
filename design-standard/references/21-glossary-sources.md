# 21. Glossary and sources

### 21.1 Glossary

| Term | Meaning |
| --- | --- |
| Baseline grid | Horizontal lines all text sits on, keeping columns aligned |
| Bleed | Artwork extending past the trim so no white edge appears after cutting |
| C2PA / Content Credentials | Open standard for provenance metadata showing how an image was made or edited |
| CMYK / RGB | Ink (subtractive) and light (additive) colour models |
| Critical print size | Smallest text size at which reading reaches full speed |
| Figure–ground | Separation of an object from its background |
| Gutter | Space between columns |
| Kerning / tracking | Space between a specific pair of letters / across a whole word or line |
| Leading | Distance between lines of text |
| Measure | Line length, usually counted in characters |
| OKLCH | Perceptually uniform colour space: lightness, chroma, hue |
| Orphan / widow | A lone word or line stranded at a line, column or page break |
| Processing fluency | Ease with which something is perceived; drives liking and trust |
| Prototypicality | How typical a design looks for its category |
| Safe zone | Area free of platform overlays and crop risk |
| Scrim | Semi-transparent layer behind text to raise contrast on images |
| Tangency | Two edges almost touching, creating visual tension |
| Type scale | Fixed set of sizes in a consistent ratio |
| Visual weight | How strongly an element pulls the eye |
| WCAG | Web Content Accessibility Guidelines, the international accessibility standard |
| x-height | Height of lowercase letters; drives apparent size and legibility |
