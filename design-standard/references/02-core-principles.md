# 2. Core design principles

Every strong design has one focal point, a clear first-second-third reading order, and elements that visibly belong to one system. The principles below work together; a fix to one usually helps the others.

| Principle | MUST / SHOULD rule | How to check |
| --- | --- | --- |
| Hierarchy | MUST have a clear first, second and third read; built with size, weight, contrast, position and space, not decoration | Name the reading order in under 5 seconds |
| Emphasis / focal point | MUST have one dominant focal point unless the brief calls for equal weight | Blur test: one element still stands out |
| Contrast | SHOULD use large differences (size ratio of at least 2:1 between levels, strong light/dark difference); small differences read as mistakes | Grayscale test |
| Alignment | MUST align every element to an edge, axis, baseline or grid line | Draw guides; nothing floats |
| Proximity | MUST group related items and separate unrelated ones; gap between groups at least twice the gap within | Can you circle each group? |
| Repetition | SHOULD repeat styles for the same kind of content (labels, icons, cards, bullets) | Same-role items look identical |
| Balance | SHOULD distribute visual weight on purpose: symmetrical (formal, stable), asymmetrical (dynamic), radial (focus) | Does one side feel heavy with no reason? |
| Scale and proportion | SHOULD size by importance, using a consistent ratio (see 3.4 and 4.4) | No arbitrary in-between sizes |
| Whitespace | MUST keep margins and breathing room; whitespace is active, not empty | Does anything touch an edge or neighbour? |
| Rhythm | SHOULD space repeated items at regular intervals | Equal gaps between equal items |
| Movement / flow | SHOULD lead the eye from hook to message to call to action | Trace the eye path; it ends at the CTA |
| Unity | MUST make all elements feel like one system (colour, type, shape, tone) | Remove the logo: still one family? |
| Variety | MAY vary within the system to avoid monotony; never at random | Variation is deliberate and repeated |

### 2.1 Visual weight: what makes an element heavy

Visual weight rises with **size, darkness, saturation, contrast, complexity, isolation, faces and eyes, text with meaning, and position** (elements high or to the right feel heavier in left-to-right cultures). Balance a large pale area with a small dark or saturated one. **\[Practice; perception research\]**

### 2.2 Common failure patterns

- **Everything is important:** many bold, large or coloured items cancel each other out. Pick one hero.
- **Near misses:** elements almost aligned or almost the same size look like errors. Make things clearly the same or clearly different.
- **Equal spacing everywhere:** removes grouping. Vary space deliberately to show structure.
- **Decoration as hierarchy:** boxes, badges and shadows used instead of size and contrast. Remove them and fix the hierarchy.
- **Competing focal points:** a strong photo, a big number and a loud badge all fighting. Subordinate two of them.
